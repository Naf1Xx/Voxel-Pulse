# Support

Contact the Voxel Pulse developer at [voxelpulse@outlook.com](mailto:voxelpulse@outlook.com) for support and privacy enquiries. For security concerns, use email rather than posting sensitive details publicly.

Visit the [Voxel Pulse repository](https://github.com/Naf1Xx/Voxel-Pulse) for project information. If its public Issues feature is available, use it for non-sensitive bug reports.

Include the launcher version, operating system, reproduction steps and a redacted error message. Never post passwords, access or refresh tokens, device codes, account identifiers, or unredacted logs.

For account recovery use [Microsoft account support](https://support.microsoft.com/account-billing).
