Approved design requirements / Утверждённые требования

The project owner has adopted the following design requirements: no developer-operated user account database; no advertising or analytics telemetry; no transmission of account tokens to the developer; diagnostic reports sent only at the user's initiative; and a means to delete account data on request. These are approved design requirements, not a certification that every current build complies. Deletion in external services and copies held by third parties may require separate action.

Владелец проекта утвердил требования к разработке: отсутствие собственной серверной базы пользовательских аккаунтов, рекламной и аналитической телеметрии и передачи токенов разработчику; отправка диагностических отчётов только по инициативе пользователя; возможность удаления данных аккаунта по запросу. Это утверждённые требования, а не подтверждение соответствия каждой текущей сборки. Удаление данных в сторонних сервисах и их копиях может требовать отдельных действий.

Launcher account data

The 0.1.0 implementation uses Microsoft OAuth device code flow and communicates with Microsoft identity, Xbox Live, XSTS and Minecraft Services (profile and entitlement endpoints). The account record contains the profile identifier, username, Xbox user identifier, Microsoft refresh token, Minecraft access token and expiry. The Windows account store protects saved data using DPAPI and supports removing records. UI sign-out and server-side revocation have not been fully verified.

Local storage and Prism / Локальное хранение и Prism

In the inspected 0.1.0 build, the default Windows data directory is %APPDATA%/VoxelPulse (overridable). Built-in accounts are stored in config/accounts.dat. The optional Prism integration reads and can copy the existing Prism accounts.json into the launcher’s separate prism directory; DPAPI protection of the built-in store must not be assumed for this separate file. UI and CLI logs rotate at 5 MB with five archived files each. The diagnostic report writer prunes its matching local reports to ten. A static scan of 431 classes in 11 project JARs found no recognizable analytics SDK references or hard-coded developer telemetry endpoint; it does not rule out dynamic network destinations, native code, external software or changes in later builds.

В проверенной сборке 0.1.0 каталог данных Windows по умолчанию — %APPDATA%/VoxelPulse (может переопределяться). Встроенные аккаунты хранятся в config/accounts.dat. Интеграция Prism может копировать существующий accounts.json в отдельный каталог prism; защита DPAPI встроенного хранилища не подтверждена для этого файла. Журналы UI и CLI ротируются при 5 МБ, по пять архивных файлов; для соответствующих локальных диагностических отчётов предусмотрено ограничение до десяти. Статический анализ 431 класса в 11 JAR не выявил известных SDK аналитики или жёстко заданного адреса телеметрии разработчика, но не исключает динамические адреса, нативный код, сторонние программы и изменения последующих сборок.

Content and logs

The inspected code includes endpoints for Modrinth, CurseForge, Mojang/Minecraft downloads, Fabric, Quilt and Prism metadata. Account-related logs may contain a username. Redaction rules exist but do not guarantee fully anonymous logs. Never share unredacted logs or tokens.

Website / Сайт

The website stores language, sound, volume and visual-effects preferences in browser local storage. You can remove these preferences by clearing site data in your browser. The reviewed website code requests public releases from the GitHub API without sending browser credentials. No data collection forms or analytics scripts were found in that code; this does not establish the absence of processing by the hosting provider. The GitHub Pages host records visitor IP addresses for security. See GitHub privacy statement and Microsoft privacy statement.

Дополнительные сведения на русском языке

Встроенная авторизация использует OAuth device code Microsoft для входа в собственную учётную запись пользователя, проверки права на Minecraft и получения профиля. Запись аккаунта содержит имя и идентификатор профиля, идентификатор Xbox, токен обновления Microsoft, токен доступа Minecraft и срок его действия. Встроенное хранилище защищено DPAPI; удаление записи предусмотрено, однако полное удаление и отзыв токенов при выходе ещё проверяются.

В коде предусмотрены обращения к сервисам Modrinth, CurseForge, Mojang/Minecraft, Fabric, Quilt и источникам метаданных Prism. Наличие адреса в коде не означает фактическую отправку запроса. При использовании сторонних сервисов действуют их собственные условия и политики. Никнейм может присутствовать в локальных журналах; маскирование не гарантирует полного обезличивания.

Сайт сохраняет настройки языка, громкости, звука и визуальных эффектов в localStorage; их можно удалить через настройки данных сайта в браузере. В проверенном коде сайта не обнаружены формы сбора данных или скрипты аналитики. Запрос публичных релизов GitHub выполняется без учётных данных браузера. GitHub Pages обрабатывает IP-адреса посетителей в целях безопасности. Применимость требований к локализации, трансграничной передаче, основаниям и срокам обработки обращений поддержки ещё уточняется.
