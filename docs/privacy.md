# Privacy notice — review draft, not effective

This draft describes the publicly documented project design. It is not a final privacy policy and must not be used as the Entra privacy URL until verified and approved.

## Microsoft authentication

Voxel Pulse is designed to use Microsoft's OAuth device code flow. The project documentation states that the launcher does not directly collect Microsoft account passwords. Microsoft handles the account sign-in. Minecraft API approval and live authentication are not yet confirmed.

## External services

The project documents Modrinth integration and an optional Prism Launcher integration. These services may have their own privacy notices. See [Microsoft privacy statement](https://privacy.microsoft.com/privacystatement) and [Modrinth](https://modrinth.com/).

## Required verification before publication

Confirm the responsible operator and privacy contact, actual categories of account and device data, token storage and deletion behavior, diagnostics and telemetry, recipients and hosting logs, retention, legal bases, international transfers, children's data and applicable user rights. Do not assume that data stays local or that telemetry is absent without checking implementation and deployment.
